# Instruções do projeto WZZY AI

Responda em português. Leia os módulos e testes relevantes antes de editar.
Mantenha o runtime em Node.js 24 com APIs nativas, sem dependências de produção.
Preserve o estudo original e atualize a documentação quando mudar contratos.
Execute `npm.cmd test` e `npm.cmd run check` no Windows ou equivalentes `npm`.
Não descreva demonstrações roteirizadas como avaliação de um modelo real.
Relacione conclusões aos resultados observados e explicite verificações pendentes.
Estas instruções orientam comportamento; o controlador define as permissões.
