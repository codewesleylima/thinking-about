# Instruções do projeto YZZY BLACK

Responda em português. Leia os módulos e testes relevantes antes de editar.
Mantenha o runtime em Node.js 24 com APIs nativas e o Codex oficial com versão fixada; justifique novas dependências.
Preserve o estudo original e atualize a documentação quando mudar contratos.
Para compreender ou replicar esta base em outro projeto, leia REPLICAR.md, docs/replicacao/README.md e docs/replicacao/spec.json. Siga requisitos e critérios, distinguindo implementado, parcial e planejado.
Shell do host exige --allow-host-shell fornecido pela pessoa. Não ative por inferência: ele pode acessar arquivos/rede com privilégios do usuário, sem as garantias do modo restrito.
Execute `npm.cmd test` e `npm.cmd run check` no Windows ou equivalentes `npm`.
Não descreva demonstrações roteirizadas como avaliação de um modelo real.
Relacione conclusões aos resultados observados e explicite verificações pendentes.
Estas instruções orientam comportamento; o controlador define as permissões.
